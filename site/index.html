How it works

  
Four steps. You mostly just press Enter

  
ai-kit fills in the survey from what it found on your machine. You mostly confirm

  

    
1
scan
Finds your IDEs and the AI inside them, CLI assistants, local models, cloud keys (names only), MCP servers you already have, and the stack of every project in your home folder. It reads folder names and manifests, not your code


• Cursor        Cursor Agent, Claude Code
• Antigravity   Gemini (built-in)
• Projects · 16 React ×4 · FastAPI ×3

    
2
survey
What you build, your stack, your databases and services, what annoys you about your assistant, which assistants you use, alone or in a team. Arrow keys, Esc to go back. Anything the scan already knows is ticked


Databases you work with?
❯ ◉ PostgreSQL
  ◉ Redis
  ◯ MongoDB

    
3
plan
A short core list we chose by hand, with a before/after for each tool. Then the best matches from the catalog, ranked by stars, downloads, Smithery usage and Hacker News. Every item says why it's there


✓ ponytail      less code → fewer tokens  ★160k
✓ graphify      code graph, not re-reads  ★125k
✓ postgres-mcp  postgres · 135k dl/wk

    
4
install
Into each assistant you picked. Claude Code through its CLI. Cursor, Windsurf, Antigravity, VS Code and Cline by editing their config, with a backup next to it. Gemini and Codex through CLI or config. Then a check of what actually installed


$ claude mcp add postgres-mcp -- uvx postgres-mcp
$ ~/.cursor/mcp.json → mcpServers.postgres-mcp
✓ postgres-mcp   Claude Code   connected
✓ postgres-mcp   Cursor        connected

Safety

  
It changes things on your machine, so the rules are strict

  

    
The scan reads names, not code
Folder names and manifests like package.json and pyproject.toml. Cloud keys are shown by provider name only. Nothing is sent anywhere

    
Configs are backed up first
Every config ai-kit edits gets a .bak-<time> copy next to it. It adds entries, never overwrites yours

    
Unverified is labelled unverified
Catalog finds show stars, last commit, downloads and discussion, and carry an unverified label. ai-kit offers to install a package only if it really exists on npm or PyPI

    
No telemetry
No analytics, no phoning home. The only network calls are GitHub stars, the catalog download and the registries you see in the output

    
Zero dependencies
Node's standard library only. npx ai-kit downloads one file. There is no supply chain under it to worry about

  






  
Commands

  
Everything from the terminal

  

    
CommandWhat it does

    
      
npx ai-kitScan, pre-filled survey, plan, HTML report, install into the assistants you picked

      
npx ai-kit scanInventory only: IDEs, AI extensions, CLIs, local and cloud models, MCP servers, project stacks, and what's missing

      
npx ai-kit doctorAudit your current setup: junk plugins, heavy config files, duplicates, tokens per request, dollars per month

      
npx ai-kit doctor --fixSame, then turn the junk off after you confirm

      
npx ai-kit discoverCatalog matches for your stack plus a live GitHub search, with install commands for each assistant

      
npx ai-kit updateRe-plan from your saved profile without the survey. Picks up new catalog entries

      
--dry-run · --yes · --json · --lang xxShow without changing anything · no prompts for the core list · machine-readable output for CI · interface language
